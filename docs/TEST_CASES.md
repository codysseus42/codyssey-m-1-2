# 기능 테스트 케이스

배포된 사이트에서 손으로 확인하는 시나리오다. 위에서부터 순서대로 하면 앞 단계의 결과를 다음 단계가 이어 쓴다.
`[AI]` 표시는 GPT 답변이라 문장은 매번 달라도 된다. **기대 결과의 핵심 내용만 맞으면 통과**이고,
틀리면 대부분 `backend/service.py`의 시스템 프롬프트 규칙만 고치면 된다(오른쪽 칸에 해당 규칙).
